# تهنئة زواج مشاعر عبد المنعم 💍✨

موقع تهنئة وتبريكات زواج فاخر واحترافي مبني باستخدام **React + Vite** بدون Backend وبدون قاعدة بيانات، مصمم كهدية إهداء خاصة للعروس الغالية **مشاعر عبد المنعم**.

---

## 🌟 المميزات
- **شاشة هبوط فاخرة (Landing Hero):** خلفية متدرجة ملكية، خط عربي أنيق (Cairo & Amiri)، وزر نابض متوهج.
- **مؤثرات احتفالية فخمة:** مدافع ألعاب نارية وورود وقلوب وكونفيتي باستخدام `canvas-confetti`.
- **موسيقى هادئة ورومانسية:** مشغل صوت أنيق مع موجات ترددية، يعمل بنغمات قيثارة دافئة عبر Web Audio API بدون انقطاع، مع إمكانية تشغيل ملف MP3 مخصص.
- **رسالة التهنئة بالآلة الكاتبة:** تأثير Typewriter تدريجي مؤثر مع إمكانية العرض الفوري.
- **كروت الدعوات والأمنيات الثلاث:** بطاقات Glassmorphism بتأثير الزجاج وتوهج ذهبي.
- **معرض صور تفاعلي (Gallery Slider):** سلايدر ناعم مع مصغرات ونافذة تكبير Lightbox، مع صور توضيحية فاخرة قابلة للاستبدال بسهولة.
- **تصميم متجاوب ومتوافق مع الموبايل بالكامل (Mobile-First) ودعم RTL كامل.**

## 🛠️ التشغيل محلياً (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة النهائية للإنتاج
npm run build
```

---

## ✏️ التخصيص والتعديل السريع

جميع نصوص وصور الموقع مجمعة في ملف واحد لتسهيل التعديل:
- **ملف البيانات:** `src/data.js`
  - لتغيير اسمك في التوقيع: عدّل الحقل `signature.name` من `[اكتب اسمك هنا]` إلى اسمك.
  - لتعديل الرسالة أو نصوص التهنئة: عدّل مصفوفة `message.paragraphs`.
  - لتعديل بطاقات الدعوات: عدّل كائنات `wishes`.
- **استبدال الصور:** ضع صوركم في المجلد `src/assets/photos/` وقم بربطها في `src/data.js`.
- **إضافة موسيقى MP3 خارجية (اختياري):** ضع ملف صوتي باسم `wedding-music.mp3` داخل مجلد `public/`.

## 🚀 خطوات النشر على Render (Static Site)

1. ادخل إلى لوحة تحكم [Render Dashboard](https://dashboard.render.com).
2. اضغط على **New +** ثم اختر **Static Site**.
3. اربط حساب GitHub واختر المستودع `mashaer-wedding`.
4. أدخل الإعدادات التالية:
   - **Name:** `mashaer-wedding`
   - **Branch:** `main`
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `dist`
5. اذهب إلى قسم **Redirects/Rewrites** في الإعدادات وأضف القاعدة:
   - **Source:** `/*`
   - **Destination:** `/index.html`
   - **Action:** `Rewrite`
6. اضغط **Create Static Site**، وسيكون الموقع متاحاً برابط سريع ومجاني!
